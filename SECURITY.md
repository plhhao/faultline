# Security policy

## Supported versions

Security fixes are made on the latest released version and the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory reporting for this repository, or contact the repository owner
privately through GitHub. Include a clear description, affected version, steps
to reproduce, and any suggested mitigation.

Reports are acknowledged within 7 days. Please allow time for investigation and
a fix before public disclosure.

## Scope

Faultline is a testing proxy. Test configurations, certificates, credentials,
event output, and managed-state files are operated by the deployer and are not
safe to publish unless independently reviewed and sanitized.
